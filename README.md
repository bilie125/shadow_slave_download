# Telegram-бот «Теневой Раб» — финальная версия с Ephemeral Messages

## Что изменилось

Пользовательский интерфейс в группах теперь работает через Telegram **Ephemeral Messages**.
Команды и ответы бота в группе видит только конкретный пользователь и бот — они не появляются как обычные сообщения для остальных участников.

Актуальный Bot API поддерживает ephemeral-команды через `BotCommand.is_ephemeral`, а aiogram 3.31 поддерживает их и отправку персональных сообщений/документов через `EphemeralMessageParameters`. 

## Возможности

- Единая SQLite-база всех глав.
- Импорт старых глав из DOCX.
- Импорт файла ссылок `Глава N: https://telegra.ph/...`.
- Автоматический приём новых сообщений из Telegram-чата.
- Поддержка обычных ссылок и скрытых Telegram `text_link`.
- Загрузка текста Telegraph без интерфейса страницы, изображений и навигации.
- Сохранение Telegraph URL даже если текст временно не загрузился.
- `/retry_telegraph` — повторная догрузка всех сохранённых ссылок без текста.
- `/chapters 3000-3177` — проверка диапазона и выбор TXT/DOCX/EPUB.
- `/volumes` — выбор заранее настроенного тома.
- `/add_volume 1 1 570` — создание/изменение тома.
- Защита от одновременной повторной генерации для одного пользователя.
- Удаление временных файлов после отправки.
- `/set_source_chat` — ограничение автоматического парсинга конкретным чатом.
- Быстрый DOCX через прямой OOXML без `python-docx` при генерации.
- Заголовки DOCX создаются как настоящий `Heading 1`, поэтому Word распознаёт их как заголовки.
- EPUB получает стабильный идентификатор книги.

## Как работает приватность в группе

Пользователь пишет в группе:

```text
/chapters 680-1200
```

Если команда объявлена Telegram как ephemeral, сама команда невидима остальным участникам. Бот показывает этому пользователю персональное меню:

```text
📚 Главы 680-1200 готовы.

Выберите формат:
[ TXT ] [ DOCX ] [ EPUB ]
```

После выбора формата бот редактирует персональное ephemeral-сообщение, формирует файл и отправляет DOCX/EPUB/TXT также только этому пользователю.

Для этого бот должен быть администратором группы. Telegram указывает, что администратор-бот может отправлять ephemeral-сообщения конкретному участнику группы независимо от 15-секундного окна ответа на входящее ephemeral-действие.

## Установка Windows / Ubuntu

```text
python -m venv venv
```

Windows:

```text
venv\\Scripts\\activate
```

Ubuntu:

```text
source venv/bin/activate
```

Затем:

```text
pip install -r requirements.txt
```

Создай `.env` рядом с `bot.py`:

```env
BOT_TOKEN=токен_бота
ADMIN_IDS=123456789
BOOK_NAME=Теневой Раб
DB_PATH=data/book.db
```

Запуск:

```text
python bot.py
```

## Первичная загрузка

1. Запусти бота.
2. В личном чате с ботом отправь `/import_docx`.
3. Отправь DOCX с главами.
4. Отправь `/import_links`.
5. Отправь TXT со строками `Глава N: URL`.
6. В исходном Telegram-чате с новыми главами выполни `/set_source_chat` от имени администратора.

После этого бот автоматически сохраняет новые главы, если сообщение содержит `Глава N` и ссылку Telegraph. Если ссылка скрытая, она берётся из Telegram `text_link` entity.

## Пользовательские команды

```text
/start
/status
/chapters 3000-3177
/volumes
```

В группах эти команды настроены как ephemeral. В личном чате они остаются обычными.

## Админские команды

```text
/import_docx
/import_links
/set_source_chat
/set_source_chat -100123456789
/source_chat
/add_volume 1 1 570
/delete_volume 1
/retry_telegraph
```

В группах админские команды также объявлены ephemeral, поэтому ответы администратора не засоряют общий чат.

## Важное

Бот не пытается читать старую историю Telegram задним числом. Старые главы загружаются DOCX/TXT, новые сообщения обрабатываются после запуска бота.

Для ephemeral-команд используется aiogram 3.31+.
